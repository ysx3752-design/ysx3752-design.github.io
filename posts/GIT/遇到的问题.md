# 遇到的问题

## 未关联仓库

1. `\$ git push origin master fatal: 'origin' does not appear to be a git repository fatal: Could not read from remote repository.  Please make sure you have the correct access rights and the repository exists.`

   报错的意思是：<strong>Git 找不到名为 </strong>`origin`<strong> 的远程仓库。</strong>

   通常是因为你在这个新文件夹里执行了 `git init` 和提交，但**忘记把远程仓库的地址绑定给它了**。

   解决办法：添加远程仓库地址

   **第一步：检查是否已有远程仓库**

   ```
   git remote -v
   ```

   - 如果**没有任何输出**，说明确实没绑定。执行第二步。

   - 如果输出里有 `origin`，但地址不对，先执行 `git remote remove origin` 删掉它，再执行第二步。

   **第二步：添加你真实的 GitHub/Gitee 仓库地址**

   ```
   git remote add origin 你的仓库地址.git
   ```

   <em>(注意：如果你之前在网页端建仓库时勾选了“初始化 README”或“添加 .gitignore”，远程仓库就已经有内容了，此时直接 push 会被拒绝。你需要先执行 </em>`git pull origin master --allow-unrelated-histories`<em> 拉取合并，然后再 push。)</em>

   **第三步：再次推送**

   ```
   git push -u origin master
   ```
