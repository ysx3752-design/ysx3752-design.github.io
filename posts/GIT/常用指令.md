3. 提交所有文件到暂存区：git add .

4. 提交单个文件到暂存区：git add 文件名

5. 将暂存区内容提交到本地仓库：git commit -m “提交说明"

6. 推送：git push -u origin 分支名（没有分支**仓库为空时需要添加-u，不是空的可以不加.**

---

## GIT日志

1. 查看所有日志：git log

2. 简化成一行日志：git log --oneline

3. 查看仓库信息（更改记录等）：git status

---

## GIT版本

1. 查看版本号：git log --oneline

2. 回退到想要的版本：git reset --hard 版本号

3. 回到之前版本后，如果发现找不到未来记录，可使用`git reflog`查看git的所有操作记录。

---

## 文件的忽略

在.git文件夹同级目录下新增.gitignore文件，写入忽略规则，可以在执行git相关操作的时候忽略改文件。

语法为：

```gitignore
# .gitignore内容：
password.txt

# 其余用法：
# 忽略文件夹
css
# 忽略文件夹下的某个文件
css/index.js
# 忽略文件夹下某类文件
css/*.js
```

## GIT的分支

1. 创建分支：git branch 分支名

2. 查看当前版本库下所含有的所有分支：git branch

3. 切换分支：git checkout 分支名

4. 分支合并：

   - 切换分支：git checkout master（master为主分支）

   - 合并：git merge 目标分支名

   为了更好理解，比如我建了一个名为abc的分支。

   `git branch abc`

   我在该分支下进行了添加文件abc.txt，随后进行分支上的提交。

   `git add .`

   `git commit -m '添加abc.txt文件'`

   `git push -u origin abc`

   这样就完成了在分支上的操作，随后再并入主分支master。

   `git checkout master`

   `git merge abc`#在master分支上合并abc分支。

5. 分支删除：git branch -d 分支名

   如果分支的修改没有被合并，Git会提示你是否确认要删除，如果你不在乎分支的内容，可以使用`git branch -D 分支名`来强制删除分支。

6. 分支合并时的冲突解决：

   当两个分支修改了同一个文件的同一处内容并分别提交过，在合并时 Git 无法自动判断保留哪一份，就会产生冲突（Conflict）。

   - **第一步：查看冲突文件**  
     输入 `git status` 查看状态，标红或提示 `both modified` 的就是发生冲突的文件。

   - **第二步：打开文件，手动修改内容**  
     用文本编辑器（如 VS Code、记事本等）打开冲突文件，Git 会在冲突区域自动生成三行标记符号：

     ```text
     <<<<<<< HEAD
     当前所在分支的代码
     =======
     要合并进来的分支代码
     >>>>>>> 目标分支名
     ```

     **各符号的具体含义**：
     - `<<<<<<< HEAD`：标记当前所在分支代码的开头。
     - `=======`：两条分支代码的分隔分割线。
     - `>>>>>>> 目标分支名`：标记合并进来的分支代码的结尾。

     **具体修改操作**：
     1. **决定代码的取舍**：
        - 如果只想要当前分支的代码：删掉 `=======` 下方合并分支的代码。
        - 如果只想要合并进来的分支代码：删掉 `<<<<<<< HEAD` 下方当前分支的代码。
        - 如果两边修改的代码都要：把两段代码都保留，按需要的顺序整理排列。
     2. **彻底删除三行 Git 标记符**：
        - 将包含 `<<<<<<< HEAD` 的整行删掉；
        - 将包含 `=======` 的整行删掉；
        - 将包含 `>>>>>>> 目标分支名` 的整行删掉。
     3. **最终保存**：
        确保文件中只留下整理好的正常代码，没有任何 `<<<<<<<`、`=======`、`>>>>>>>` 符号后，保存文件。

   - **补充：如果想放弃合并**  
     如果在处理冲突过程中不想合并了，输入以下命令即可取消合并，代码恢复原状：
     ```bash
     git merge --abort
     ```
