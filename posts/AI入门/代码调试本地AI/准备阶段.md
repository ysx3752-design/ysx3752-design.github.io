# 准备阶段

## 环境准备

在 Windows 上搭建 Python 环境，可以使用 Python  + 使用 VS Code。

### 安装 Python

1. **下载**：去官网 [python.org/downloads](https://www.python.org/downloads/) 下载最新的 Windows 安装包（`.exe`）。
2. **安装**：双击运行安装包，**务必勾选底部的 `Add python.exe to PATH`**（将 Python 添加到环境变量），然后点击 `Install Now` 一路下一步即可。
3. **验证**：按 `Win + R` 键，输入 `cmd` 回车打开黑窗口。输入 `python --version`，如果能看到版本号（如 `Python 3.12.x`），说明安装成功。

### 安装代码编辑器（VS Code）

1. **下载**：去官网 [code.visualstudio.com](https://code.visualstudio.com/) 下载并安装 VS Code。
2. **装插件**：打开 VS Code，点击左侧的“扩展”，搜索 **`Python`**，点击安装。

## 选择合适的路线

通常有两种路线：CPU推理和GPU推理，也就是内存和显存。

由于笔记本配置，我选择的是**CPU推理**。如果你的配置较好，请善用网络搜索。

### 1. 建环境、装 CPU 版 PyTorch

建议在powershell上进行操作。

```
cd D:\2_Agent\2_Qwen-0.8b  #你的目录
python -m venv .venv
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1

pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -U transformers accelerate pillow safetensors
```

确认 Transformers 认识这个架构：

```
python -c "from transformers import Qwen3_5ForConditionalGeneration; print('ok')"
```

如果报错找不到，装主分支：

```
pip install -U "transformers @ git+https://github.com/huggingface/transformers.git@main"
```

### 2.脚本测试

```
import os
import torch
from transformers import AutoProcessor, Qwen3_5ForConditionalGeneration, TextStreamer

# 1. 先设置路径和线程数，路径一定要改成你自己的！
MODEL = r"D:\2_Agent\2_Qwen-0.8b\models\Qwen3.5-0.8B"
torch.set_num_threads(max(1, os.cpu_count()))

# 2. 加载处理器和模型
processor = AutoProcessor.from_pretrained(MODEL)
model = Qwen3_5ForConditionalGeneration.from_pretrained(
    MODEL,
    dtype=torch.bfloat16,
    device_map="cpu",
    low_cpu_mem_usage=True,
)
model.eval()

# 3. 准备输入
messages = [
    {"role": "user", "content": [{"type": "text", "text": "用三句话介绍你自己。"}]}
]
prompt = processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
inputs = processor(text=[prompt], return_tensors="pt")

# 4. 创建 streamer
streamer = TextStreamer(
    processor.tokenizer,
    skip_prompt=True,
    skip_special_tokens=True,
)

# 5. 生成
    model.generate(
        **inputs,
        max_new_tokens=256,
        do_sample=False,
        repetition_penalty=1.1,
        streamer=streamer,     # 如果想看流式输出，加上这行
    )
```

牌没有问题！测试结束。
